# 2.1 | CHANGELOG

## ✨ ARMOR FEEDBACK

Armor can now visually react when it takes damage.

- Added new effects for normal armor damage;
- Heavy durability loss now produces a stronger effect;
- Added unique effects for fire, explosions, projectiles and fall damage;
- Added a new effect when Mending restores armor durability;
- Every effect can be enabled or disabled individually.

## ⚙️ CUSTOMIZATION

- Added Mod Menu support;
- Added a new in-game configuration screen.

## 🛡️ MOD COMPATIBILITY

- Added support for Advanced Netherite armor;
- Added support for Deeper and Darker's Warden armor.

## 🔧 FIXES

- Fixed the default leather armor icon color on newer Minecraft versions.

## 📦 VERSION SUPPORT

Future updates will be available for:

- Minecraft 1.20.1;
- Minecraft 1.21.1;
- Minecraft 1.21.11;
- Minecraft 26.1.2;
- Minecraft 26.2.

Support has ended for Minecraft 1.21.2–1.21.10, 26.1 and 26.1.1.
