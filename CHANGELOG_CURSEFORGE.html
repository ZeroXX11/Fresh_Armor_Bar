2.2 | CHANGELOG


✨ ARMOR TRANSITIONS

  • Armor icons now animate smoothly when armor is equipped, removed or replaced;
  • Mixed armor sets and half-armor icons now transition naturally to their new positions;
  • Added smooth transitions for armor values above 20 points and for the Elytra indicator.

⚙️ CUSTOMIZATION

  • Armor bar animations can now be enabled or disabled;
  • Improved the Mod Menu configuration screen with clearer buttons and new icons.

🛡️ MOD COMPATIBILITY

  • Added compatibility with the Armored Elytra mod;
  • Added support for BetterEnd armor and Elytra;
  • Added support for BetterNether armor.

🔧 IMPROVEMENTS

  • Improved armor bar rendering performance;
  • Resource-pack texture changes now appear correctly after reloading resources with F3+T.
